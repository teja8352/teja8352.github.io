Atlas — Enterprise Design System

Atlas is a design system and component library I built to unify a sprawling enterprise UI. It ships accessible-by-default components, design tokens, and full Storybook docs.

Source
Atlas — Enterprise Design System

Why a Design System

Twelve teams were each rebuilding buttons, modals, and forms with subtle inconsistencies and accessibility gaps. Atlas consolidated them into one tokenized, tested source of truth.

Button.tsx
export const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  ({ variant = 'primary', ...props }, ref) => (
    <button ref={ref} className={cn(buttonVariants({ variant }))} {...props} />
  )
);

What shipped

  • 48 components with full keyboard + screen-reader support
  • Design tokens synced from Figma via Style Dictionary
  • Automated visual regression tests in CI

Atlas cut new-feature UI build time by roughly 40% and brought every product to WCAG 2.1 AA compliance.
