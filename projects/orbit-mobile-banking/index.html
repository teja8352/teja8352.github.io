Orbit — Cross-Platform Mobile Banking

Overview

Orbit needed to feel instant even on flaky connections, while meeting strict financial security standards. The answer was an offline-first architecture with a reconciling sync engine.

Highlights

  • Biometric (FaceID / fingerprint) auth with secure enclave key storage
  • Offline-first ledger using WatermelonDB with conflict-free sync
  • End-to-end TypeScript shared between app and backend

Orbit is the smoothest banking app our users have ever rated.
